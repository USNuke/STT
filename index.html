Rules Reference

Borg Round Structure

  • Adaptation Phase (1d6)
  • Power Reallocation Phase (1d6)
  • Production Phase (1d12)
  • Activation Phase (1d6)
  • Collapse / Persistence Phase (optional)

Mothership Board

  • Engines, Weapons, Shields, Hull (1–12 cubes each)
  • Global Integrity Track: 16 / 12 / 8 / 4
  • Starting configuration: 4 cubes in each row
  • Hard constraints: min 1 cube, max 12 cubes per row

Adaptation Phase (1d6)

  • 1–2: No change
  • 3–4: Adaptation Level +1
  • 5: Adaptation Level +2
  • 6: Adaptation Level +1 and roll Adaptation Effect (1d6)

Power Reallocation (1d6)

  • 1: No change
  • 2: Engines → Shields
  • 3: Shields → Weapons
  • 4: Weapons → Hull
  • 5: Hull → Engines
  • 6: Adaptive Shift (roll 1d4 twice, move 1 cube twice)

Production Phase (1d12)

  • 1–2: +3 Assimilation Stock
  • 3–4: Build 1 Cube (else +2 AS)
  • 5: Build 1 Cube +2 AS
  • 6: Convert 3 AS → +1 Cube (else +1 AS)
  • 7–8: Reinforce (move 1 cube to Hull)
  • 9: No production
  • 10: +1 AS per Adaptation Level (min 1)
  • 11: Forced Assimilation Check
  • 12: Escalation Surge

Activation Phase (1d6)

  • 1–2: 2 activations
  • 3–4: 3 activations
  • 5: 4 activations
  • 6: 5 activations

Activation Procedure

  • Select Cube: closest to Developed System, else Home System, else random.
  • Target Selection: 1d20 with modifiers for enemy ships, adaptation level, outnumbered sectors.
  • Action Selection: 1d12 (Advance, Engage, Assimilate, Interdict, etc.).

Collapse / Persistence (1d6)

  • 1–2: Normal collapse
  • 3–4: Retain one key lane
  • 5: Cubes immune to displacement
  • 6: Ignore collapse

Sanity Check

  • Total cubes = 16
  • No row below 1 or above 12
  • Dice tier matches Weapons row
  • Impulse matches Engines row
